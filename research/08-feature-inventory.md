# Feature inventory: what spool does today

*Grades: **shipped solid** = in the published npm release with no known defect on record. **shipped with caveats** = published with a named defect/limit, or merged to main but absent from the published release (the caveat is stated each time). **roadmap** = exists only as an open issue.*

## 0. Release ground truth

- Published releases: 0.1.0 and 0.2.0, both 2026-07-22 (`CHANGELOG.md`). 0.1.0 carried the whole core (verbs, canvas, daemon, flows, player, scenarios/mock, snap, autostart, init/open, skill); 0.2.0 added the update loop (#30) plus fixes.

- No LICENSE file and no `license` field in `package.json`; #36 records "Repo currently has no LICENSE" and plans sustainable-use at repo-public.
- Package: `spool.page`, bin `spool`, Node >=22 (`package.json`). README: "macOS-first; the canvas wants Chrome (WebKit renders transformed iframes blurry)" (`README.md`).

## 2. Daemon + canvas (`src/daemon/`, `src/ui/`)

### Daemon

- **One per-machine local server** at `http://localhost:7766` (dev split: 7767 via `SPOOL_PORT`), Hono on `@hono/node-server`; any spool verb auto-starts it (`src/daemon/lifecycle.ts`, `README.md`). Routes: registry/projects, `fs/list` (folder picker), per-project frames projection, thumbs, canvas state, flows, selection, geometry writes, trash, editor open, upgrade, scenarios/fixtures, SSE event streams, frame documents `/p/:project/frames/:frame`, player `/play/:project`, pinned vendor modules (`/vendor/react.js`, `spool.js`, `spool-jsx.js`, `spool-term.js`), fonts, favicon, UI (`src/daemon/app.ts:206-709`). Grade: shipped solid.
- **Update loop (#30)**: daemon asks the npm registry after listen then daily, caches `~/.spool/update.json`, failures silent; UI toast + `spool status` line surface it (`src/daemon/update-check.ts`, `src/ui/update-toast.tsx`). Grade: shipped solid (0.2.0's headline feature).
- **Security posture**: player and directly opened frame documents currently run project code on spool's trusted origin; the control API has no request authentication; scenarios/fixtures are CORS-open; the compiler can follow imports outside `design/` including symlinks. All on record in #41 (open, ready-for-agent, "hardening: isolate project code from spool authority"). Canvas frames do already run in `allow-scripts` opaque-origin iframes (#41, ADR 0003). Grade: shipped with caveats — a landing must not claim hardened isolation of untrusted repos (#41).

### Canvas

- **Infinite canvas, home-built DOM** (no library): zoom 0.02×–32× anchored at the cursor, exponential wheel zoom, cubic ease-out camera flights (`src/ui/canvas/camera.ts`, ADR 0001). Grade: shipped solid.
- **Frames render live in iframes**; the canvas is "a projection of the disk, never a source of truth" (`CONTEXT.md`, ADR 0003). Live mode (near frames run) vs design mode (time frozen, clicks select elements); double-click enters a frame and interaction goes inside, Esc leaves (`CONTEXT.md`, changelog 0.1.0). Grade: shipped solid.
- **Arranging/resizing with snap**: drag-move and edge-resize snap to other frames' edges and centers with guide lines, "the Figma pattern" (`src/ui/canvas/snap.ts`). Geometry writes back to `frame.json` (`src/daemon/geometry.ts`). Grade: shipped solid.
- **Frame lifecycle — warm pool + wake queue**: near frames play; offscreen/tiny frames freeze into a warm pool (cap 24 mounted frames); overflow demotes oldest-seen to its still with a goodbye self-capture; every mount drains through an ordered wake queue (entered → selected → wake-requested rows → nearest center, 3 per sweep); hibernated frames boot fresh on return (`src/ui/canvas/lifecycle.ts`, ADR "warm pool and wake queue replace the hibernation timer", PR #47). Grade: shipped with caveats — on main, unreleased (`f2a12b0`).
- **Thumbnails/stills**: PNG cache under `design/.spool/thumbs/`, self-captured from the canvas with a Playwright fallback writing the same store (`src/daemon/thumbs.ts`). Grade: shipped with caveats — #46: captures can't embed web fonts (SVG-as-image can't fetch), so stills render fallback faces; every capture path affected.
- **Selection**: click selects frames; design mode descends to elements; multi-element selection with hover previews (`196101f`, unreleased); selection is served read-only to agents with source path + lines via JSX location stamping (`src/daemon/selection.ts`, `src/daemon/jsx-span.ts`). Grade: core shipped solid; multi-element on main, unreleased.
- **File tree / element-tree sidebar (#50/#51)**: one collapsible left panel — pages above the active page's frame list, each frame row expandable into its element tree in design mode; rows select, switch, and jump (double-click flies to frames or opens the editor at elements), never author; shift ranges, ⌘/Ctrl toggles; drag-edge resize snapping closed to a rail; terminal frame rows offer no element tree (`src/ui/canvas/sidebar.tsx`, `element-tree.ts`, commits `a4d7c53`, `6c4d014`, `8fe05e5`). Grade: shipped with caveats — on main, unreleased.
- **Pages (#45)**: a one-level folder under `frames/` without a frame entry is a page — its own canvas, portal chips where an arrow leaves the page, frame names unique project-wide, walks cross pages freely, the player ignores pages (`src/ui/canvas/pages.ts`, `portal-chips.tsx`, skill `frames`). Grade: shipped with caveats — on main, unreleased.
- **Spatial keyboard navigation** between frames (arrow-key beam search, 640px max distance) (`src/ui/canvas/spatial-navigation.ts`, `8da1a0c`). Grade: shipped with caveats — on main, unreleased.
- **Context menu**: exactly "Play from here / Open in editor / adaptive export / Move to Trash" (`src/ui/canvas/context-menu.tsx` docstring). Open-in-editor jumps to the source line via launch-editor; Trash moves the frame folder to the OS Trash (the only file-destructive gesture spool has). Grade: menu core shipped solid; export entry unreleased.
- **Frame export**: one selected frame downloads a PNG immediately ("Export as PNG"); a multi-selection opens a dialog ("Export N frames…") choosing PNG or a single PDF with one page per frame in canvas order, built with pdf-lib client-side (`src/ui/canvas/frame-export.ts`, `export-dialog.tsx`, `3cfcd86`). Grade: shipped with caveats — on main, unreleased; captures share #46's font-fidelity bug.
- **Flow arrows on canvas**: drawn from the element that causes the walk, solid `will` / faint `might`, verified marks from real walks, portal chips across pages, dedupe fix `1bca8bc` (`src/ui/canvas/flow-arrows.tsx`). Grade: 0.1.0 arrows shipped; the read-from-source map (#34) unreleased.
- **Home + folder picker**: registered-project cards built from thumbnail covers; "+" opens a picker that browses the daemon's disk, resolves by walk-up, and offers init in place (`src/ui/home.tsx`, `src/ui/picker.tsx`). Grade: shipped solid.
- **External-link confirm**: absolute links inside prototypes raise a stay/open dialog instead of navigating the canvas away (`src/runtime/external-link-dialog.tsx`, `817f7a2`). Grade: shipped with caveats — on main, unreleased.
- **Collision notice** when frames overlap (`src/ui/canvas/collision-notice.tsx`). Grade: shipped solid.

### Terminal frames (the second frame kind — all of it on main, unreleased)

- **What they are**: a folder with `term.tsx` instead of `frame.tsx` is a terminal frame — an OpenTUI React app the daemon runs **as a real process in a real PTY**, its cell grid painted live on the canvas by an xterm emulator in the frame document. "The second and final frame kind" (`CONTEXT.md`; #42 spec; ADR 0006 "terminal frames run real processes"; `25f5233`).
- **Toolchain**: spool provisions its own pinned bun 1.3.14 + OpenTUI 0.4.5 + React 19.2.7 idempotently under `~/.spool/toolchain` on first terminal-frame use; resolution rides `NODE_PATH`, so `design/` never gains a package manifest. Bun targets: darwin-arm64/x64, linux-x64/arm64, win32-x64 (`src/daemon/term-toolchain.ts`).
- **Supervisor/PTY mechanics**: the provisioned bun runs spool's supervisor, which owns the PTY; the daemon speaks wire frames to it over plain pipes; SIGWINCH delivers real terminal resizes (`src/daemon/term-exec.ts`, `91259fd`, `1a88d35`). Daemon-side, a headless xterm + serialize addon holds the screen truth: attach late and receive the screen so far; warm = SIGSTOP (kernel-frozen, zero CPU); hibernated = killed with the screen serialized to `design/.spool/term/<frame>.screen`; an exited process keeps its last screen dimmed with an exit-code chip and revives only on save or enter — never auto-respawn; a dying TUI's leave-alt-screen wipe is stashed so its last artifact survives (`src/daemon/term-sessions.ts`).
- **Cells**: born 80×24; one cell = 9×20px (pinned JetBrains Mono at 15px), so 80×24 = 720×480; canvas resize snaps to whole cells with a cols×rows badge and reaches the process as a real resize (skill `terminals`, `src/term/cells.ts`).
- **Input**: an entered terminal owns the whole keyboard — Esc, Ctrl+C, Ctrl+Z all reach the process (parity law); the one way out is platform-modifier+Esc, shown in the chip (`src/runtime/term-keys.ts`, PR #49, `ab1fb8e`).
- **Flows**: `import { term } from "spool/term"; term.go("checkout")` — the target rides an OSC escape the daemon intercepts; edges come only from the static parse; walks verify (skill `terminals`, `src/term/osc.ts`, `src/daemon/nav-sites.ts`).
- **Player**: terminal frames are live in walks — the walk attaches to the real process, output streams, every key reaches it, a `term.go` fired by the TUI advances the walk; restart gives fresh processes; canvas and any number of players mirror one daemon-held session (PR #48, `5b74883`, skill `terminals`).
- **Verify**: `spool shot` rasterizes the current grid to SVG in the pinned font — no browser, "the pixels are the process's own screen"; a never-run terminal has no screen to shoot; `spool logs` is html-only (skill `terminals`/`verbs`).
- Grade for the whole area: **shipped with caveats — merged to main with a dedicated stability pass (PR #52: resize, replay, death, exit), but not in any published npm release**; spec is #42.

## 3. Frame authoring contract (skill `frames`; ADR 0002)

- **Birth by file write**: `design/frames/<name>/frame.tsx` default-exporting one React component — no registration, no `spool new`; it appears on the canvas live. Frames render nowhere outside spool. Grade: shipped solid.
- **Geometry sidecar** `frame.json` `{x,y,w,h}` (integers, px): the one file both hands write; spool fills it in (390×844, placed beside its page's frames) and rewrites it as the human drags/resizes. Grade: shipped with caveats — #32: the daemon materializes the sidecar the moment a folder appears, racing agent-authored sidecars.
- **Variants**: `--`-suffixed sibling folders (`checkout--empty`), complete frames and valid walk targets. Renaming = renaming the folder (update `data-go`/`ui.go` literals or the map marks them missing); deleting = deleting the folder. Grade: shipped solid.
- **shared/**: `shared/ui/` kebab-case components under the boundary law (props only, importing `"spool"` there fails the compile — what keeps them product-importable); `shared/lib/utils.ts` ships `cn()` (clsx + tailwind-merge). Grade: shipped solid.
- **Single token file** `shared/tokens.css`; `shared/transitions.css` (player transitions, plain CSS); `shared/fonts.css` injected into every document; `shared/scenarios/*.json`; `shared/fixtures/*.json`; `shared/assets/` "yours to organize — but project files are not served in v1". Grade: shipped solid (the assets limit is stated contract, see next).
- **Libraries via importmap**: `design/` never gets a `package.json`; imports resolve through `shared/importmap.json` to URLs (esm.sh); init pins clsx, tailwind-merge, class-variance-authority, and motion; spool pins react, react-dom, react-dom/client, react/jsx-runtime, and `"spool"`, and its pins always win — exactly one React (19.2.7) runs. React-based libraries must externalize React (`?external=react,react-dom`). Plain `.css` imports land in the document as-is. Grade: shipped solid.
- **Null-origin sandbox and consequences**: canvas frames run with scripts inside opaque-origin iframes (ADR 0003, #41). Consequence on record: the async Clipboard API can reject outright in frames — the graduated landing frame carries a hidden-textarea `execCommand` fallback for its own copy buttons (`design/frames/landing/frame.tsx:37-70`). Grade: shipped solid as a stated constraint.
- **No static asset serving in v1**: a relative `<img src>` has nothing to answer it — images/media by absolute URL or data URI, fonts hosted or data-URI'd in fonts.css (skill `frames`/`styling`). #32 notes the direct cost: "a shipped spool.page will want an og image / favicon, which v1's no-static-assets stance can't serve." Grade: shipped solid as a stated constraint; the constraint itself is landing-relevant.
- **Document assembly**: spool owns the document — pinned React, Tailwind compiled at serve, preflight, tokens, fonts, import map, mock + flow runtime injected; `html/body/#root` at `height: 100%` so `h-full` reaches the frame edge; frames are blank until React commits, covered by thumbnails; esbuild compile with content-hash cache and JSX location stamping (`src/daemon/compile.ts`, `document.ts`, `jsx-span.ts`). Grade: shipped solid.
- **App-owned files**: `design/canvas.json` and `design/.spool/` are spool's — "the one law: never write app-owned files" (skill overview, `design/AGENTS.md`). Grade: shipped solid.

## 4. Flows (skill `flows`; ADR 0004)

- **Markup sugar**: `data-go="<frame>"` on any element walks on click (nearest ancestor wins, anchors get preventDefault, variants valid targets); `data-transition="<type>"` on the same element names the move for transition styling. Grade: shipped solid.
- **Code API** (`import { ui } from "spool"`): `ui.go(name, patch?)` (merge patch into state, push frame onto stack, walk), `ui.back()` (pop; empty stack quiet no-op), `ui.state` (flat mutable shared object, any write re-renders subscribers), `ui.use()` (subscribe hook). Coded walks carry no transition name. Walking to a nonexistent frame logs and stays put (`src/runtime/frame-runtime.ts`, skill `flows`). Grade: shipped solid.
- **Sessions and seeding**: a session seeds from a scenario before first render — a frame never renders unseeded; the canvas hands the session to the next frame on a walk; the player starts a fresh session per load (reload = restart); `?scenario=<name>` names the seed and a different name restarts. Grade: shipped solid.
- **Declared vs walked arrows**: every literal `data-go` target, `ui.go(name)`, and `term.go(name)` in a frame's folder is an edge read from source — solid `will` when unconditional, faint `might` inside a branch (ternary/if/switch/&&/||, both branch literals drawn); unreadable destinations (`ui.go(routeFor(state))`) draw nothing and are reported; playing never adds/removes arrows — real walks only flip `verified` marks, dropped when the from-frame's source changes; headless boots never verify (ADR 0004 "flow map read not walked", skill `flows`). Grade: shipped with caveats — the source-read rework (#34, `1e5efb7`) is on main, unreleased.
- **`spool flows` output**: `{frames, edges, unreadable}` with per-edge sites `{path, line, conditional?}`, `verified`, `missing` (typo'd literals included) — "the todo list when wiring a flow" (skill `verbs`). Grade: as above.
- **The player**: `/play/:project` composes every frame component into one light document (View Transitions cannot cross iframe boundaries — same-document VT is the whole point); walks are View Transitions: crossfade by default, morphs wherever two frames share a `view-transition-name`; each swap carries its direction (forward/back/restart) plus any `data-transition` type, styled in `shared/transitions.css` with `::view-transition-*`; reduced motion respected; the floating pill = back, name-stack trail (last 3, full path in the title), restart, motion toggle, hint toggle (highlights coded-navigation elements), close; frame letterboxed at native size on a near-black stage, phone-ready on a plain URL (`src/daemon/play.ts`, `src/runtime/player-chrome.tsx`, `CONTEXT.md`). Grade: shipped with caveats — #53 (open bug): the letterbox scale lives *inside* the frame's document, so self-measuring frames see visual boxes where they expect layout boxes (gBCR off by the letterbox factor); a parity-law violation with a frame-side workaround on record.
- **transitions.css**: plain CSS, verbatim into the player bundle (`src/daemon/play.ts` `PlayerBundle.transitions`). Grade: shipped solid.

## 5. Scenarios and the mock backend (skill `scenarios`, `mock`)

- **Scenarios**: `shared/scenarios/<name>.json` = `{ "state": {...}, "mock": {...} }`, both keys optional; `default.json` is what canvas plays and shot/logs boots load; player URLs take `?scenario=`; the player's restart re-reads the file (edit-seed-restart on one URL); a missing/broken scenario never blanks the frame — empty seed + console error visible in `spool logs`. Frames never branch on scenario name. Grade: shipped solid.
- **Mock backend**: inside a session, relative URLs are the fake backend, absolute URLs the real network; only `fetch` is intercepted (no XHR, no WebSocket). Zero config: `fetch("/api/<name>")` answers with `shared/fixtures/<name>.json`, nested names allowed, any method (writes are theater). Scenario `mock` rules per route: exactly `status`, `fixture`, `latency`, `body`; method-prefixed keys win over bare paths; any non-rule value serves verbatim; top-level `latency` applies to every mocked route; unmatched relative fetch 404s with a message naming the fix; malformed fixtures fail loud. No programmable mock by design. Grade: shipped solid.

## 6. Styling (skill `styling`)

- **Tailwind v4 compiled at serve**: utilities in JSX arrive as finished CSS — theme, preflight, only the utilities used; no config file, no user build step; compiler pinned per format version (tailwindcss 4.3.3, `package.json`); arbitrary values and variants work. Grade: shipped solid.
- **Tokens under `@theme`**: `shared/tokens.css` is the only stylesheet the compile reads (plus relative `@import`s; `@plugin`/`@config` unsupported): `:root` verbatim for distilled product variables, `@theme` for spool-born tokens picked up as utilities, `@theme inline` to bridge — "shadcn v4's shape", importable by non-Tailwind consumers. Grade: shipped solid.
- **`cn()`/`cva`**: compose classes with `cn()` only (never template literals); variant components ride pinned cva. Grade: shipped solid.
- **Plain CSS**: `<style>` in a frame or plain `.css` imports for what classes can't say; transitions.css and fonts.css stay plain. Grade: shipped solid.
- **Motion pinned**: `import { motion } from "motion/react"` for interaction feel inside a frame; screen-to-screen motion belongs to the flow layer, never animated from a frame; other animation libraries go in the import map. Grade: shipped solid.
- On record in #32: the dogfood identity type ramp tops out at `--text-lg` 18px — display-size type underived (a canvas-token note, not a product defect).

## 7. The ship story — what gates a landing

- **`spool build` does not exist.** #35 (open, `ready-for-agent`): "spool build — static export of a checkout" — a daemonless CLI verb compiling `design/` into a self-contained static bundle (frames via the existing esbuild+Tailwind pipeline, baked canvas JSON, read-only viewer + player, Playwright-baked thumbnails, `shared/` carried; laws: daemonless, dumb files out, read-only). Sequenced "after the current frontier (#14 skill test, #17 React-frames bench)"; blocks spool cloud.
- **The landing itself depends on #35**: `design/frames/landing/frame.tsx` docstring — "Ships via spool build (#35); design ticket #31." #31's stated fog: "how the chosen frame ships as the static site (export path, host), docs beyond the README, license/pricing wording."
- **spool cloud is spec-only**: #36 (open) — "Not for implementation yet"; renders committed git refs, GitHub App + static serving, guest links, public-repo-free; blocked on #35; onspool.page bought 2026-07-23.
- **Open issues a landing must not contradict**:
  - #53 player letterbox breaks self-measuring frames (parity-law bug, open).
  - #46 stills render fallback faces — thumbnails/exports don't embed web fonts (open).
  - #41 hardening not landed — opening an untrusted repo's design is "not yet safely distinct from trusting local application code" (open, ready-for-agent).
  - #32 dogfood findings (open, needs-triage): `spool stop` hang (fix on main), silent shot fallback, sidecar race, player favicon.ico 404, no unregister verb, `--allow-scripts=esbuild` on hardened npm configs, no og-image/favicon possible under the no-static-assets stance.
  - #42 terminal frames spec (open — implementation merged to main, unreleased).
  - #31 landing page (open — this work).
- **No LICENSE** file in the repo (verified; #36 plans sustainable-use fair-code at repo-public). "no cloud, no accounts" is true today; "open source" is not yet a claim the repo backs with a license text.
- **Full open-issue list at time of writing** (8): #53, #46, #42, #41, #36, #35, #32, #31 (`gh issue list`, 2026-07-23).

## 8. What README.md and docs/ lead with

- README first line: "**A canvas where the frames are alive.**" Then: "Agent-authored TSX frames on an infinite canvas: arrange them spatially, link them into walkable flows, and feel an app (interactions, motion, state, real inputs) before it exists. Code is the document; the canvas is a projection of it. A design space is just a `design/` folder inside your product repo: local-first, git-tracked, no cloud." Status line: "Status: wayfinding." Install: `npm i -g spool.page`, "Node 22+. macOS-first; the canvas wants Chrome (WebKit renders transformed iframes blurry)." Four-command quickstart: `spool init` / `spool open` / `spool serve` (daemon at `http://localhost:7766`) / `spool autostart`. "Frames are authored by your agent: `spool skill` prints the complete contract."
- package.json description: "Live prototyping canvas: agent-authored TSX frames on an infinite canvas, repo-native." Homepage `https://spool.page`.
