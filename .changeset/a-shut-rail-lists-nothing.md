The shut pages rail is now just the edge that opens it. It used to carry a strip of folder icons, one per page, which was a second navigator that disagreed with the first: it listed every page at whatever depth, so a project with a folded tree showed more folders shut than open, and the icons said nothing about which folder was which without hovering each one. Opening the rail is how you look through the pages, so the strip no longer offers a worse way to do it.
