Breaking: `spool selection` prints a `<selection>` block instead of JSON, and prints nothing when nothing is selected. It is the same text a prompt from the agent chat carries, so a script that read the JSON list needs updating, and an agent reading either surface now reads one thing. A frame is its name, its path and its size. An element is its frame, what the source calls it, and its path with the lines it spans, with its excerpt on the line below. Every entry always carries its path, and when excerpts are dropped to stay inside a budget the block says how many.
