Get it now finds your clone of a team project's repo in your usual code folders (`~/code`, `~/dev`, `~/Developer`, `~/Projects`, `~/src`, `~/repos`, `~/GitHub`) even if spool never opened it, and remembers a folder you pick with "In a checkout…". Each place in the sheet says what spool found there before anything happens. A design/ that is already the team's is taken as it is, another project's design/ is dimmed, and on a branch from before the move the sheet names the move commit and the command that brings it in, then carries on by itself once you run it.
