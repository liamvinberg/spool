You can now reorder elements by hand. Select an element and press an arrow key to move it one step among its siblings, or pick up the Edit tool and drag it to where it should go. A drag that starts inside a row of a list moves the whole row, and the row moves in the array that draws the list. Each press and each drop is one change to the file and one step of undo. The frame reloads behind its last picture so nothing blinks, and its state starts over. When the file doesn't write the siblings side by side, for example when one comes from a condition, a note under the element says why and offers to ask the agent.
