Export a frame as one HTML file. Right-click a frame and pick Export…: the menu turns into the export choice right where you clicked, with png, pdf and html, and Enter exports. An HTML file opens in any browser, offline and with nothing installed, as the bare frame with every frame its links reach, so you can walk the flow by clicking. Pick Only this frame to leave the rest out. The choice names any frame that needs the internet to work. With several frames selected you get one file each, as with PNG. The menu then shows the file being built and where it landed; in the Mac app the file goes straight to Downloads and Show in Finder reveals it. Exported files are now named after the project and the frame, like `kaffe-checkout.png`, and the menu remembers the format you used last.
