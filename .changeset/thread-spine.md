The threads leave the row above the transcript and become a column down the agent rail's outer edge.

A conversation is one 34px cell in it, in the order things last happened, with the open one carrying the accent. Nothing in the column is a name. Hover a cell and the thread arrives to the left of it over the log, with what it is called, the last line it drew, how long ago that was and a ✕; a press opens it. The column costs the same 34px whether there is one conversation or twenty, where the row ran out of width at four.

Which thread you are in is written once, on a nameplate above the log.

A thread is named by the frames it wrote rather than by what you asked. An ask is a sentence and a name is a label, so every name used to be a sentence cut off wherever the room ran out; a frame name is short, already unique in the project and already what the conversation was about. A thread that has written nothing yet is still its ask, and one nobody has said anything to is still new. The name is derived every time it is read and stored nowhere, so there is nothing to rename and nothing to keep in step; what spool writes down still keeps the first thing you said, which is a different fact and stays true.
