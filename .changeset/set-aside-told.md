**Collisions told to their writer.** When a save to a team project is set aside, the agent that wrote it now hears so on its next command, `spool check` fails until it is settled, and `spool set-aside` lists it and settles it with `mine` or `theirs`. On the canvas the notice is gone: a quiet count after who's here opens the list, with the same three choices. Two copies signed in as the same account are told as two of your copies, not as a teammate, and a long file name no longer runs under the buttons.
