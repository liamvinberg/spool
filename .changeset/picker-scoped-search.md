The folder picker searches the folder you are standing in. The path stays in front of what you type, so `~/projects/art` finds the folders under projects that answer to art, and each hit says where it sits under that folder. Type `~/` in front to search every folder under home instead.

The picker no longer says nothing matches while it is still looking. Spool indexes home in the background when it starts and again each time the picker opens, so the first keystroke answers from an index that is already there.
