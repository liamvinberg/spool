After a layout edit, Properties says for every affected use whether the frame really laid it out. It reads each padding and margin side in the direction that use writes in, both gap axes, offsets, and sizes against the box the use actually got. When a minimum, a maximum or a flex rule decided the size instead of the edit, it says constrained and names the rule. When it cannot prove what the frame did, it says unverified rather than guessing.
