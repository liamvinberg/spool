You can edit text in the frame again. Click the words of a selected element and the caret is there at once; type, and the frame changes as you type. Clicking away or pressing Enter saves once in the background, Escape puts the words back, and the frame you edited is not reloaded for its own save. Headings with line breaks and inline spans, paragraphs, links and words passed to a shared component all save into the file with the right escaping. Text that is an expression refuses by name, with an Ask agent action that opens the composer holding what you tried. Undo and redo put the file and the frame back, and a step whose file changed underneath is dropped with a note.
