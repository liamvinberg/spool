A new project's tab opens with its name ready to type, so you can name it straight away or leave it untitled for the agent to name. Any project on this Mac can be renamed from its tab: double-click the name, or choose Rename… from the tab's menu, and its folder is renamed with it. Open…'s dialog now sits in the middle of the window like the others instead of hanging from the top. A chat opens on the model it last reported instead of "Loading…", and opening the model menu while it loads no longer starts the wait over.
