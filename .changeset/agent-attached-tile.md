An image attached to the agent composer can be looked at, not only dropped. Pressing the tile holds the picture up over the rail at size, in the same overlay a screenshot from a tool call opens in, and esc or a press on the backdrop puts it down. Taking the reference back is now a ✕ in the tile's top right corner rather than the whole tile, so the only thing you could do with your own picture is no longer delete it.
