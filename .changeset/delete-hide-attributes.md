Delete, hide and edit attributes by hand. Press ⌫ on a selected element and it goes from the frame and from the file, taking its own line with it when it stood on one; an element that is all of a shared component deletes at the call that renders it, and one written inside an expression refuses with the reason and an Ask agent action. The rail's attributes section hides and shows an element by writing the `hidden` class — hide then show leaves the file exactly as it was — and types `href`, `alt`, `title` and `aria-*` where the file spells them literally, naming the expression where it does not. Dropping a picture on an image writes the file beside the frame, its import, and the `src` that reads it. All of it undoes, in the file and in the frame.
