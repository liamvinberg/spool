A frame on screen no longer blinks when it reloads. Whether an agent wrote to it, a shared file it uses changed, a teammate's save arrived, you chose Reload (from the menu or with R), or the canvas reconnected, the frame keeps showing what it last drew until the new version is ready. Your own edits already worked this way. If the new version fails to build, the error shows right away.
