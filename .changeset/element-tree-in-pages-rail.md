The pages rail now shows the elements of the frame you are editing. Press E and the frame's row opens into a tree of its elements, labelled the way the code writes them: the component or tag, the element's own words, and the file's name where the code moves into another file. A list drawn by `.map()` reads as one `.map ×N` row with its rows numbered under it. Click a row to select its element, or hover it to outline the element on the canvas. A click on the canvas opens the tree down to what it selected. Hidden elements, empty ones and ones sitting behind something are rows too, so the tree is how you reach them. Press V and the tree folds away. Selecting an element deep in a page that repeats the same markup, like a card drawn twice, now selects the one you clicked rather than the first copy.
