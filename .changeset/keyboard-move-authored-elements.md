Move the held element with the arrow keys. An element its parent lays out changes places with the sibling beside it, in the source, as long as every one of those siblings carries a stable key of its own; siblings without one refuse before anything is saved, with the reason ready to hand to an agent. An element the file already places freely moves by a pixel instead, ten with shift, in the unit the file already writes that placement in. Holding the key is one move, one save and one press of undo, and Escape puts it back. A sibling the app is not currently showing still holds its place in the file, so one press can move the source past it without anything appearing to move.
