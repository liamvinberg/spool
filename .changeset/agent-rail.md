The agent is on the canvas. The right rail is a chat now: type what to change, press Enter, and your own Claude Code answers there instead of in another terminal. Your words land in the log the instant you send them. The wait before the first reply shows as a turning mark with a clock on it, so a second of nothing reads as work rather than as a hang. A thought the agent has on the way settles into one quiet line with how long it took. The reply arrives as it is written, at the rate it is written, with its bold, lists, code and fenced blocks drawn rather than left as markdown source. A long reply pins its own first line so the answer does not scroll away before you have read it. The frame the agent writes repaints on the canvas while the message explaining it is still landing.
