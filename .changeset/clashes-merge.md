When you and a teammate change the same file in a team project at once, Spool now merges the two line by line, the way git does, so both changes stand and nobody is asked anything. Only when you both changed the same lines are you told, in one notice at the foot of the canvas instead of a mark on every frame: Use theirs, Use mine, or Ask agent to fix, which opens a new agent thread with every clashed file (or copies the prompt when there's no agent on this Mac). Sync messages such as "Sync paused" moved to the same place and can be closed.
