The properties rail writes again. Typing or stepping a layout, spacing, size, typography or appearance value changes the element in the frame at once, and Enter or blur saves one class change into the file in the background: the frame takes the new class and stylesheet without a reload, and the row's label lights once the file has the value, with no "Saving…" to wait on. A bare number in a length field means pixels, so `700` in width writes `w-[700px]`; the token menus still offer the scale. Classes inside `cn("…", cond && "…")` are edited in the literal and the condition stays; a computed className refuses with the file and line and a link that copies the path, plus the Ask agent door. Undo and redo put the file and the element back, and a write whose file changed underneath refuses, re-reads the element and lifts the preview.
