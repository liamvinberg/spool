When you and a teammate save the same file in a team project at nearly the same time, the save that reaches spool.page first stands. Yours is kept in the team's history, your file takes theirs, and each frame that shows the file gets a mark saying so. From the mark you can compare the two versions, put yours back on top, or hand both to your agent, which starts only when you press. Coming back online with many of these at once shows one summary instead. An edit always beats a delete, so a file you deleted while a teammate was still editing it comes back, and you are told. Changes to `canvas.json` never collide: each page's place and the order are merged one at a time.
