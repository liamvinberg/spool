Open… now takes a folder, a .spool file or a link, and does the one thing that fits. A folder that already has designs, or a folder inside one, opens at once. A folder without designs, a .spool file or a git link asks first in a small sheet: Design in this folder, Import, or Clone, which shows its progress and then opens what it cloned. A spool.page link to your team's project gets it onto this Mac and opens it. When nothing answers, spool says so and keeps what you gave it so you can fix it and try again. You can also drop a folder or a .spool file on Home, or paste a path or a link there. In the Mac app, Open… is the system's own open panel. Import… is gone as a separate button, since Open… does its job.
