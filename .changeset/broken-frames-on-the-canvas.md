A frame that fails to compile or throws as it starts now says so on the canvas. Its last good picture stays, dimmed, with a red edge and a red name. Near enough to read, it shows the error and an Ask agent to fix button, which hands the error to a new thread in the Agent pane, or copies the prompt when no agent is set up. The Pages list marks the frame with a red dot, and a shut folder holding one gets the dot too. It all clears as soon as the frame works again.
