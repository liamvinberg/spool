**A first run.** The first time spool opens on a computer, a small window plays the ripple and its sound, then sets up your agents: it installs Claude Code, Codex or pi and signs them in, or tells you the one line to run when it can't. You can try Spool Cloud with your team or pass it by, and the window then grows into spool. Run it again from Help.
