The agent, its model and effort, and the permission mode are now one choice for the whole machine. Every new chat in every project starts on what you last picked, and nothing switches it back on its own. Before anything is picked, spool starts on the first agent you have installed, Claude Code before Codex before pi, on Auto-edit. A permission mode picked while the agent is working is saved at once and takes effect from the next turn. Requests the agent already made still wait for your answer. Choices saved per project by earlier versions are carried over once, taking the most recent.
