Home has two ways in now: New project and Open….

New project asks nothing. Home's button, ⌘N, the menu's New Project and New on a team's page each make the project at once, as the next untitled folder in your projects location (a team's under a folder named for the team), and open it with the Agent pane ready on the right. Your first message names the project, so a tide planner becomes tide-planner before the agent writes anything. Close an untitled project with no frames and it goes to the Trash, with Undo to bring it back. The New project dialog, with its name and location steps, is gone.

Open… takes a folder, a .spool file or a link, and does the one thing that fits. A folder that already has designs, or a folder inside one, opens at once. A folder without designs, a .spool file or a git link asks first in a small sheet: Design in this folder, Import, or Clone, which shows its progress and then opens the repo, or offers Design in this folder when it has no designs yet. A spool.page link to your team's project gets it onto this Mac and opens it. When nothing answers, spool says so and keeps what you gave it, so you can fix it and try again. You can also drop a folder or a .spool file on Home, or paste a path or a link there. In the Mac app, Open… is the system's own open panel, and a .spool file opened from Finder asks the same way before it imports. Import… is gone as its own button, since Open… does its job.
