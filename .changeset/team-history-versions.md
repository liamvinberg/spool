The History pane on a team project lists versions. Current version is the top row, and each row below is the moment someone's saves ended. Pick a row and the canvas shows the page as it stood then: what that version changed is marked and ringed, the rest steps back, and a frame it deleted stands dashed where it was, with Bring back. ↑ ↓ step through versions and Esc goes back to now. Restore this version… lists each frame that differs from now, all ticked, so restoring part of it is unticking; a shared file that changed since is offered, off. It reads Same as now when nothing differs, so a restore always changes something. This replaces Compare with now, the Restore… menu, and Restore on a file's line.
