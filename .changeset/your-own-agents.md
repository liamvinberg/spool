Breaking: the built-in spool agent is gone. The agent rail now runs the agent you already use, Claude Code or pi, with its own login, models and settings. Pi shows its live models, marks the ones running on your computer as local, and has no permission menu because it never asks. Old spool chats stay readable but can't be continued. With no agent installed, the rail shows an install line for each one with a copy button, and checks again when you come back to the window.
