Get it now works in a checkout whose design/ spool never synced. Files older than the team's take the team's version, a frame the team deleted stays deleted, your new files go up, and only a file you changed where the team has its own version is set aside on the canvas for you to look at. The sheet says how many files go up and how many are set aside before you press Get it.
