Added Restore to the History pane of team projects. Under an open stretch, Restore… puts a frame, a page or the whole project back to how it stood when that stretch ended, each choice showing how many files go back; a file restores from its line, and a save the team set aside is put back from under it. One question asks first, offering any shared file the frame imports that changed since, unticked, and naming the other frames that use it. A restore reaches the team as new saves, so nothing is lost: the toast that confirms it has Undo (and ⌘Z while it stands), and the restore's own row in the history has Undo this restore.
