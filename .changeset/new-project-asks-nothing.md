New project asks nothing now. Home's New project button, ⌘N, the menu's New Project and New on a team's page each make the project at once, as the next untitled folder in your projects location (a team's under a folder named for the team), and open it with the Agent pane ready on the right. Your first message names the project, so a tide planner becomes tide-planner before the agent writes anything. Close an untitled project with no frames and it goes to the Trash, with Undo to bring it back. The New project dialog, with its name and location steps, is gone.
