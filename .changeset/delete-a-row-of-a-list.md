Deleting a row of a list takes that row out of the list's own data. An element a `.map()` renders is one piece of code drawn once per entry, so ⌫ on it used to take the row off every entry at once; now it removes the entry from the array the map runs over — written beside the map or imported from another file — and only that row leaves the screen. Deleting the code that draws the rows says so and names the list instead. Opening the words on an element no longer reflows it, a handle drag cannot make a box narrower than the word inside it, and the ring keeps its handles when you zoom out and draws them whole against the edge of the frame.
