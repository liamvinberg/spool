The hand works on a project styled by plain CSS classes. Every rail row reads what the frame draws, so a font size, a colour or a radius a stylesheet set shows its value instead of an empty field; a project's own stylesheets sit in a cascade layer under Tailwind's utilities, so a size written next to a class takes effect instead of snapping back; ⏎ and F2 open the words of the element held; ⌫ with several held deletes them all as one write and one press of undo, and a rail write goes to every one of them, saying Mixed where they differ; and the rings, handles and hover outlines are clipped to the frame that draws them, with a bar on any edge the element runs past.
