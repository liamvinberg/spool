**Bring in Figma files.** Drop a `.fig` on Home (Figma's File → Save local copy, on every plan) and it becomes a new project named after the file, with your agent already rebuilding its frames, prototype links as walks. spool reads the file on your Mac with no Figma account or token: every page and frame, with its layout, text, colours, fonts, images and icons, lands in `imports/` beside design/, and `spool skill import` tells any agent how to read it.
