`spool shot` holds up better under agents making decks. On a busy machine a shot with `--at` or several shots at once now wait as long as the frame keeps answering, instead of failing on one overall deadline. A shot comes back of the source as saved: a save while it ran takes it again, and a failed shot no longer leaves an older picture where the new one goes. `--out <dir>` copies the files where you want them. A beat's file is named by the beat (`title.beat-price.png`), and `--beat` says it counts from 1 when refused. `spool url <deck page>` prints the address that plays the talk. `spool check` refuses a theme `@import` that the compile would refuse, and a font `@import url(...)` written after `@import "tailwindcss"` now loads. In a talk, a slide's own transition rules win over the stage's defaults without `!important`, and each move carries the type `forward` or `back`.
