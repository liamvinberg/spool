The agent rail can now run your installed Codex (0.151.0 or later). Pick it in the agent menu for a new chat. It uses your Codex login and settings, and the model menu lists the models and reasoning efforts your Codex reports. Ask first, Auto-edit and Bypass map to Codex's own approval rules and sandbox, edits in design/ and spool's read-only commands never ask, and a signed-out Codex asks you to run `codex login`. Spool never edits Codex's config file.
