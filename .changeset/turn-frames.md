A turn in the agent rail now shows the frames it touched as a grid of pictures, with one status line under it. While designers work, each one's frame has its place in the grid and on the canvas from the moment it starts, and the line says how many are working and how many are done. Otherwise it says what the agent is doing in plain words, like "Reading the spool docs" or "Drawing home · 278 lines". A frame the agent is writing fills in line by line before it lands. A designer's frame plays its real code into its place in about a second when it lands. Finished frames step back to a smaller size while others are still working, and a frame wears corner marks while its picture is taken. Every step the turn took is still there: press the status line to open them. Reads and searches one after another are one step, with every file and command behind it. When the turn ends the line reads how long it took.

A turn now lasts until the designers it started have finished, rather than ending when the agent first answers, so their frames are no longer cut off. Stop ends them too. A frame the agent deletes can be brought back with Put back.
