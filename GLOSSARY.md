# spool

Spool is a local-first prototyping canvas: agents author frame files on disk; people arrange them spatially and walk the flows between them. One context for the whole repo; these terms are canonical in issues, specs, tests, and code.

## Language

### System

**Project**: A product repo's `design/` folder as spool knows it, registered only by explicit `init` or `open`, never by scanning. _Avoid_: workspace

**Daemon**: The one per-machine local server every spool surface is served from.

**Mac app**: The macOS app in `desktop/`, an Electron window on the canvas the daemon serves. It bundles the published `spool.page` of its own version and runs it under Electron's own binary as Node, adopts a running daemon rather than becoming a second one, and keeps a menu bar item, so closing the window leaves the app and its daemon up and only quitting stops a daemon it started. Chromium rather than a native web view because the canvas renders transformed frames blurry under WebKit. _Avoid_: wrapper, webview

**History**: The git record of `design/` the daemon keeps by committing canvas work on an idle debounce — everything that changed lands as one commit scoped to the design folder once the folder has been quiet for 45 seconds. Both hands write the canvas and neither commits: an agent writes frame files and forgets, and the geometry a drag writes is no agent's to remember, so the daemon does it on whatever branch is checked out, from a temporary index so a half-staged change beside it is never swept in, and never pushes. The batch is read off git at fire time rather than remembered, which is what makes a `design/` left dirty by a daemon that was down just a batch pending its first window. Its message is one line, `design:` and a count of what it saved, so product history is one pathspec away and a release never sees a save. A project turns it on in `canvas.json`, where an absent key is off so upgrading spool changes no repository's posture; `history: false` in the per-user config refuses it everywhere on that machine and wins. _Avoid_: autocommit, autosave

**Team project**: A project whose `design/` a team shares live through Spool Cloud instead of tracking it in git. A `spool.json` beside `design/`, the one file the repo tracks for it, names it as `https://spool.page/<team>/<project>` and grants nothing. Every save reaches the team's other editors whole, as real files, and history never commits it. An existing project becomes one by moving in: it goes up whole, then one commit takes `design/` out of git and brings `spool.json` in. The repo its code lives in is recorded from `origin` as information, never as permission. A project without one is simply a project. _Avoid_: shared project, cloud project, mounted project

**Local copy**: One real `design/` of a team project on one machine, kept out of git by its own `.gitignore` of `*`: in a repo checkout, in a worktree, or on its own. A machine may hold several, all kept in step, and Home shows the team project as one cover; `spool remove` forgets one copy and never touches the team. "Get it" makes one on a machine that has none: in a checkout of the project's repo, or on its own under `<projects location>/<team>/<project>`. It stays one whatever branch is checked out, a branch from before the move with no `spool.json` included, and keeps no history. Git never writes to one: what a checkout, pull, reset or merge puts in `design/` is never sent, the team's version comes back over what the team has, and a file the team never had stays as git left it. A team project is known by its team and name, never by where a local copy sits. _Avoid_: mount, checkout, clone

**Collision**: A save to a team project built on a version of the file its machine had not yet seen. The save that reached Spool Cloud first stands and the later one is set aside, except that an edit always beats a delete. `canvas.json` never collides; its keys are taken one at a time. _Avoid_: conflict, overwrite

**Set aside**: What happens to the losing save in a collision. It is kept in the team's history and never applied, the writer's own files take the team's version, and only that writer is told, by a mark on each frame that renders the file. Putting it back is an ordinary new save. _Avoid_: rejected, discarded, conflict copy

**Presence**: Where each person on a team project's canvas is right now, and what they are doing there: their page, pointer, press, the frame they're inside and the frames they drag, and the view their camera shows. It rides the sync connection, which a member's browser on the read-only canvas joins too, and is never written anywhere, so it is not part of the project. One person is one account, however many local copies and browsers they have open. People only: an agent has no presence, and an outsider neither sees it nor has any. _Avoid_: awareness, multiplayer cursors

**Experiment**: A surface that stands only where `~/.spool/config.json` names it in `experiments`, switched per machine rather than per command because the daemon outlives any one of them. Off is absent rather than hidden: the names ride the boot script the canvas document already carries, so a surface that is off never renders and leaves nothing to press. The daemon carries whatever the file said and judges none of it, so a name nothing answers to does nothing — which is also what retires one. `agent-panel` was the first and it graduated into a **pane**, so a machine still naming it in config.json boots exactly as it did. `element-tree` holds back the **element tree** while its direction is still open. _Avoid_: feature flag, beta toggle

**Frame**: A folder under `design/frames/` holding a `frame.tsx` entry; the unit prototypes are made of. A frame is named by its path under `frames/` (`shop/checkout`, or `checkout` on the root page), and that full name is how every walk, verb and URL addresses it, so a folder name only has to be free among its siblings. Spool rewrites walk targets when it renames or moves frames and pages; a move made outside it leaves them for the author. _Avoid_: screen, artboard, mockup

**Variant**: A frame whose `--`-suffixed name marks it as an alternative take on its base frame (`home--empty`).

**Geometry sidecar**: The `frame.json` beside a frame's source, holding its place and size on the canvas. Both hands write it, along one seam: an agent states the size, spool states the position, and only a hand that means to move something writes a coordinate. So a size with no position is a whole sidecar rather than a broken one — spool completes it with a place beside that page's frames, which is the placement no agent can guess and therefore the overlap no agent can cause. A placement already on disk is never overwritten, and bytes that do not parse are a write in flight and are left exactly alone. _Avoid_: layout file

**Asset**: A project file whose bytes ride inside the served document instead of being fetched: an image or text file a frame imports, or a font `shared/fonts.css` names by a relative `url()`. There is no asset route and no asset URL, and the import is what puts the file in a frame's closure. _Avoid_: static file, public folder

### Canvas

**Canvas**: The infinite surface where frames are arranged; a projection of the disk, never a source of truth. _Avoid_: board

**Page**: A subfolder of `design/frames/` grouping frames into a journey; each page is its own canvas, and stands as a **page object** on the field of the page holding it. Pages hold pages, so a page's identity is its path (`explorations/chat`) and depth is a property of a page rather than a second kind of thing. The flat top level is the permanent root page, which never nests and has no row of its own, so the rail's top level is its contents; a page's own name, like a frame's, only has to be free among the folders beside it. _Avoid_: group, section, sub-page

**Page object**: A page drawn on the field that holds it, beside the frames it stands among: every frame under it, at its own geometry, scaled into one box. It is composed on the client from the projection rather than baked, so a frame edited two pages down redraws it for free and there is no second asset. Its size is the median area of the frames on the field times the square root of how many frames are under it, so a page of one frame draws one frame big; its shape is the subtree's own aspect **banded** to `[0.62, 2.4]`. A hand selects it, drags it and double-clicks to go inside; nothing about it resizes or rotates, because its size is derived and a corner handle would scale a picture. _Avoid_: page card, folder tile, group box

**Band**: One row of a folded **page object**. A subtree past 2.6:1 is too long to read at object size, so its frames are cut into bands in x order and stacked with a gutter, the move a contact sheet makes. It keeps every frame and the reading order, and it costs the one thing worth saying out loud: a folded object is a picture of _what_ is on the page rather than of _where_ it sits. Unfolded is the common case and is the frames exactly where they are. The same word names the clamp a page object's aspect is held inside, which is the rule the fold exists to serve. _Avoid_: wrap, reflow, contact sheet

**Exit**: A walk that leaves the active page, drawn on the frame declaring it: a short leader off the wall into a mono tag naming the target and its page. Pressing it travels — the page follows, the arrival is centred, the target ends up selected. Below the width its own words need it degrades to a stub on the wall. It replaced the portal chip, which #58 deleted with nothing in its place, and it is the only thing the walk layer draws: the canvas draws walks you can take, so a walk that lands nowhere has no face. _Avoid_: portal, chip, marker

**Select**: The default pointer tool, whose subject is the frame: a click takes one to arrange it, a double-click goes inside it, and holding the platform modifier borrows **Edit** for as long as it is held. Selecting a readable HTML frame leaves it visible and running while Select owns the pointer; an unreadable selection stays held behind its still. _Avoid_: interact

**Edit**: The pointer tool whose subject is the elements inside a frame. A click takes the deepest element under the pointer in one go, and the keys step from what is held: a double-click or ⏎ opens its words, or selects its children when it is a group; Esc or ⇧⏎ selects the parent, and the frame above a top-level element; Tab and ⇧Tab walk round the siblings and ⌘A takes all of them; ⇧-click adds to the selection and ⌫ deletes it. While it is on it is inert: no pointer or key event reaches any frame, and every live frame is under a **freeze**. It stays a tool, never a mode: going inside a frame is Select's, and the frame's label answers a double-click that way from either tool. Holding the platform modifier in Select borrows it for as long as it is held. _Avoid_: inspect, deep select, mode

**Hand**: The canvas tool for panning with a primary-button drag; holding Space borrows it temporarily. Each tool is also the other's transient: Space borrows the Hand anywhere, the platform modifier borrows Edit inside Select.

**Entered**: The state of a frame after a double-click or ⏎: pointer and keyboard input belong to its app, and walks happen in place. Esc leaves it. Holding the platform modifier hands the pointer back so an element can be reached; the frame keeps painting, because you are still looking at it. _Avoid_: focused, interact

**Still**: One immutable, content-addressed picture of a frame, taken by the **photo booth** once the frame has finished arriving with its own fonts and settled content: its first screen in its default scenario, never where somebody left it. It is what the canvas draws below a readable size, and it covers a frame until its document boots. A still is a placeholder, not an artifact: it is sharp up to 400 CSS px drawn width; above that, a nearby frame is live. _Avoid_: screenshot, snapshot

**Ladder**: Retired. A still is one image at one immutable URL, sized for the readable threshold; the canvas has no rung to choose. _Avoid_: variant, size, resolution

**Picture**: A frame below readable size or outside the viewport ring: its still on screen and no document behind it, for as long as nothing asks for one. _Avoid_: hibernated, unmounted, cold

**Caused mounting**: Why a frame holds a document at all: you went inside it, or it draws at least 400 CSS px wide inside a viewport expanded by 25% on every side. Its picture is never a cause: the **photo booth** makes every one, so a frame with none shows its placeholder until one lands. The readable condition bounds documents by viewport area rather than frame count. Intent holds documents too: every frame represented by the current element selection. With no element picks, Select instead holds the selected frame, or the entered frame while its modifier is down. A frame being exported is held separately. _Avoid_: warm pool, wake queue, hibernation

**Photo booth**: Where every **still** is made: the daemon's own headless browser, three tabs, loading each frame's document top level, settling it the way the canvas does, in the colour scheme the canvas shows, and taking Chrome's own screenshot at the still's size. It listens to every registered project whether or not a canvas is open, so an agent's edit to a page nobody is looking at is pictured all the same, and it takes the frames on screen in an open canvas first, then the rest of that page, then everything else. One frame's turn in a tab, from its load to its stored still, is a **sitting**: a still is kept only if the frame still exists and its source is the one photographed, and a sitting that runs past its deadline is closed, its frame keeping the old still and the reason. `spool shot` boots in the same browser. The browser closes thirty seconds after there is nothing left to photograph. _Avoid_: renderer, screenshotter, healer, job

**Errand**: Retired. The canvas used to borrow a frame to photograph it; the **photo booth** makes every still now, and the canvas never mounts a frame for its picture. _Avoid_: refresh queue, job

**Held**: A frame mounted behind its still so the Select tool has real DOM to read. An unreadable HTML selection stays held and keeps running; at readable size it resolves live, because Select must point at what is shown. This rejects cooperative pause and frozen pick geometry: entered frames already allow movement while Select owns the pointer, so neither a second runtime control nor stale geometry earns its complexity. A held terminal alone freezes, by SIGSTOP on its real process. _Avoid_: warm, paused

**Freeze**: A live frame holding its own animation, and getting it back the moment anything asks for it: rAF callbacks are held and re-delivered rather than cancelled, the animation clock holds with them so a thawed loop resumes instead of leaping, and declarative animations pause and play. Three causes. Two are "nobody is reading this frame" — the camera is moving, or a minute has passed with nothing **attending** the frame. The third is the opposite: somebody is reading one frame very closely, so the whole field holds for as long as the **Edit** tool is on, the frame being edited included, and lets go when it goes down. Timers and React state run on through it; that is the known limit of a hold the frame is never asked about. Layout is never held, only animation, so a frozen frame still lays itself out at a new size. The entered frame and any frame being copied for an export keep animating throughout, and nothing about the mount changes. This is not the cooperative pause **Held** rejects: that one wanted a frame to hold still so a tool could read it, and asked the frame itself to agree. This one is caused by what the hands are doing, needs nothing from the frame because the shim gates rAF from outside it, and ends at the next thing they do. _Avoid_: suspend, throttle, pause

**Attending**: What keeps a frame out of the idle freeze: the pointer over it, the frame selected, the frame entered, or the camera in motion. Every one of them is something the hands did, never where a frame happens to sit — freezing by viewport position would kill side-by-side comparison, which is the reason the idle window is a whole minute rather than a few seconds. _Avoid_: active, focused, visible

**Order**: The manual arrangement of pages and of the frames within a page, a canvas-wide durable in `canvas.json` beside the format stamp, committed and cloned rather than kept per machine. It is advisory over the projection — a stored name can be stale and an arrival can be missing from it, so the client merges the two — and it never touches geometry: reordering rows moves nothing on the canvas, and arranging frames on the canvas changes no row. _Avoid_: sort, index, position

**Pages rail**: The **pane** that is a file explorer over `design/frames/`, one tree of pages and the frames on them, in **order**, standing on the left **side** by default. Its verbs are folder operations, and it never writes frame source or geometry. While **Edit** is on, the frame the hand is in opens one level further into its **element tree**, so pages, frames and elements read as one continuous tree; under **Select** it is pages and frames and nothing else. The name is older than panes and stays: it is the pane titled Pages, not a column of its own. _Avoid_: sidebar, layers panel, navigator

**Place**: Where a page's **page object** stands on the field holding it, in world units, keyed by page path. A canvas-wide durable in `canvas.json` beside **Order**, and committed for the same reason: a page moved on one machine arrives moved on another. Advisory the same way — a key naming a page nothing holds is left alone rather than cleaned, and a page with no key is given one by the projection, beside its parent page's own field and never on top of anything, exactly as a frame born without a sidecar is. A place is a page's arrangement rather than its identity, so a rename carries it and a page that changes parent leaves it behind: the coordinate meant something on the field it left. On a **shelf** the daemon owns the place and writes over whatever was stored. _Avoid_: position, coordinate, layout

**Shelf**: Where pages stand on a field that holds no frames of its own. Their **page objects** have nothing to be arranged against there, so instead of a **place** a hand made they sit in rail order from the gutter, wrapped into rows the daemon lays with room under each row for the labels, and the camera fits them on every arrival, stored camera or not. Nothing on a shelf drags. The first frame written onto the field turns the shelf into the arrangement and hands it to the hand. _Avoid_: grid, auto-layout, index

**Snap**: The correction a drag applies to land a frame on something meaningful: the moved selection's bounding box onto other frames' edges and centres, or its gaps onto the spacing a **Run** already keeps. Every candidate on an axis competes in one pool and the smallest correction wins, so no kind of alignment silently outranks another, and the marks are read off the corrected geometry rather than off the winner: an alignment draws a **guide**, a hairline across the viewport; a matched spacing draws a **span**, a ticked bar inside every gap of the run carrying that value. Holding the platform modifier through the drag suppresses all of it. Resize snaps to edges and centres only: spacing is a fact about where a frame sits, not about how big it is. _Avoid_: magnetism, sticky

**Run**: The frames a spacing is measured within — everything whose perpendicular extent overlaps the dragged selection's, by any amount, ordered along the axis. Derived per drag and per axis and never declared, so a frame belongs to as many runs as it overlaps and a tall frame joins every horizontal run it spans, which is what lets the rule carry no threshold to argue about. _Avoid_: row, column, group, cluster

**Hands**: The human at the canvas. Hands own geometry and arrangement, and adjust frame source through the **write lane** and no other way; agents author it. _Avoid_: user, designer

**Rung**: Retired. There is no ladder of elements to walk down: a click in **Edit** takes the deepest element under the pointer, and the keys step from there to its parent, its siblings and its children. _Avoid_: level, depth, tier

**Ring**: The outline drawn around what is held. A frame's carries its own handles, which size the frame through `frame.json`. An element's is its own line boxes and nothing you can grab, because what an element is shaped like is the agent's to write, with the element's **name label** on its top edge; several held elements wear one dashed box round all of them, and a side an element runs past its frame on, or its content past its box, is marked in thread. _Avoid_: bounding box, gizmo, resizer

**Name label**: The small label on a held element's **ring**, saying what the element is and nothing else: the component whose whole output it is, read off React's fiber by the running document, otherwise a word for its tag (`h1` is Heading, `a` is Link, `nav` is Navigation), with a plain `div` a Group. It goes while the element's words are open, because then the outline is the only cue. A component named `Heading` and an `<h1>` read the same here; the code's own names are the **element tree**'s to show. _Avoid_: chip, badge, tag

**Element tree**: A frame's elements as rows under its own row in the **pages rail**, shown while **Edit** is on and folded away by Select. Only one frame's tree is open. It is a third reader of the one selection, beside the **ring** and the **name label**: a click on a row selects that element, a click on the canvas opens the tree down to what it took, and hovering a row outlines its element without taking it. Rows read like the code: the component whose whole output the element is, otherwise its tag (`<FoldStore>`, `<h1>`), then its own words, and the file's name where the code crosses into another file. A list a `.map()` renders is one `.map ×N` row with its rows numbered under it; a map of one row looks like any array from the page and reads as its row. Line breaks and the insides of an icon are not rows, and hidden, empty or covered elements are, which makes the tree the way to reach them. It adds no refusals of its own. It stands only behind the `element-tree` **experiment**; off, Edit leaves the rail as Select has it. _Avoid_: layers, outline, DOM tree

**Pane**: One surface of the canvas window: the **pages rail**, the **properties rail** or the agent. Each has one icon on a **rail**, and lighting it stands the pane in its **side**'s stack under a slim header carrying its icon, its title, its own verbs and a hide control. Lit panes stack in rail order, at most three to a side and none under 160px, and a pane carried by its header or its icon lands in a rail slot or above or below another pane. A drop that would break a rule is refused where it was aimed and says which: three to a side, 160px a pane, the canvas never under 480px. A pane is mounted for as long as the canvas is, so hidden, collapsed or carried to the other side it keeps its drafts and its scroll; one out of sight says what it has to say on its icon, the agent's turn while one runs and a mark once one has landed unread. Where every pane stands is one layout per browser, kept whole or not at all. _Avoid_: panel, tab, surface, widget

**Side**: The left or the right of the canvas window: a **rail** on the window's edge and the stack of lit **panes** beside it. A side has one width, 200 to 480px, which every pane in it shares (a side showing the agent is 380 to 560px, so the composer's foot and the agent menu stay on one line), and a drag let go under 144px collapses it to the rail alone rather than leaving a column too narrow to read. Collapsed, it remembers which panes were lit and lights them again when it opens. When the window is too narrow for the canvas to keep 480px, the side touched least recently collapses on its own and comes back once there is room. _Avoid_: column, sidebar, dock

**Rail**: The 44px strip on a **side**'s outer edge, always there, carrying one icon per **pane** that stands on that side. A click lights or hides that pane, ⌥-click shows it alone, and turning off a side's last lit pane collapses the side. A right-click moves the pane to the other side or takes it off the rail; a pane taken off comes back by its key or the palette, where it left. The right rail carries help and the settings cog at its foot, which are doors rather than panes. _Avoid_: strip, toolbar, dock, activity bar

**Dock**: Retired. The right column's strip of glyphs, one surface at a time, became the right **side**'s **rail**, and panes stack rather than take turns. _Avoid_: dock, column, index strip

**Properties rail**: The **pane** that shows a frame's own geometry, the x, y, width and height in its `frame.json`, and nothing about source, standing first on the right **side** by default. A held element shows the fields of the frame it is in, under that frame's name, and several held in one frame show the same fields. Nothing about an element itself is set here; its words are typed where they are drawn, and the rest is the agent's. A page shows what it is and how much is in it. The name is older than panes and stays: it is the pane titled Properties, and the agent can stand beside it in the same stack. _Avoid_: inspector, panel, sidebar

**Crumbs**: Retired. The rail no longer shows where an element sits: the element's own **name label** says what it is, and Esc steps up to its parent. _Avoid_: breadcrumb trail, path

**Write lane**: The one path from a gesture to frame source: pick an element, form a typed **op** addressed by the element's compile-time stamp, gate it, and splice the characters it named. Four ops and no more — an element's words, words a call site supplies it, the element itself out of the file, and the element moved before or after a sibling its parent writes beside it — and nothing else in spool writes what a frame draws. A move needs the two written side by side with only whitespace between them, so a sibling a condition, a list or a spread computes refuses and says which; an element that is the whole of what a component returns moves as the call that renders it. An element a `.map()` renders is the one place the characters at the stamp are not what goes: that literal is every row, so a delete or a move lands on the **item** instead, and one with no item named refuses. A hand changes the words already written, takes what is written away and reorders it; styling, layout, images, attributes, hiding, adding an element and moving one into another container are the agent's, so what a screen is made of and how it looks stay the agent's. _Avoid_: editor, mutation, patch API, source owner

**Item**: One entry of the array a `.map()` runs over, what a delete inside a mapped element takes out, and what moves when a hand moves a row. The stamp under the pointer is one JSX literal the document drew once per row, so only the running document can say which row a hand is on: the runtime notes each child's place in the array it stood in, and the pick carries the map's stamp and that index. The write lands on the array literal — beside the map, or in the file the binding is imported from — taking the entry with its comma and its own line, and the document loses the row's own element rather than the element that was picked. A move of a row trades the entry's place with its neighbours' and leaves the commas and breaks between entries where they were. An array a file cannot show as a literal is named and refused, because there is no entry to take out of a call or a prop. _Avoid_: row, list item, record

**Gate**: The answer to whether one op can be made honestly, given by parsing the file fresh at the stamp and never by consulting a mirror of it. Yes, or a **refusal**: a named reason the canvas shows on the element the moment the gesture is tried: the words are an expression, the element is the whole of what a component returns, the rows come from something with no literal to take an entry out of, a stamp that hits nothing. It is said in a note under the element, which offers to ask the agent with what was tried and goes after a few seconds or when the selection moves, and never in the notice strip. A refusal means the gesture does not apply and nothing else happens; nothing is forwarded to an agent unless the person asks. _Avoid_: validation, check, guard

**Shared definition**: An element whose stamp names a file outside the frame's own folder, which is what a component under `shared/` is. It reads and writes through the **write lane** exactly as the frame's own elements do; what differs is reach. A write lands once, in that file; the frame it was made from keeps its document, and every other frame rendering the file reloads behind its held paint. Words a call site supplies are that call's, written in the caller's file; the definition's own literal is every frame's. _Avoid_: component instance, affected use

**Span patch**: What a hand edit is on disk: a run of characters replaced, and every other byte of the file left as it was, including the author's indentation and the other attributes on the same element. A patch carries the patch that puts it back, so undo and redo are the same call. _Avoid_: diff, edit, mutation, undo receipt

**Fingerprint**: The hash of the file the canvas read, carried by every op and re-checked at the moment of writing. A mismatch refuses and re-picks rather than landing somewhere wrong, which is what lets an agent and a human work in one file at the same time. _Avoid_: version, etag, revision

### Flows

**Flow map**: The arrow layer: the link graph derived by reading frame source. Walking can verify an edge, never add or remove one.

**Navigation site**: A place in frame source that navigates — a `data-go` attribute or a `ui.go(...)` call; each site's arrow grows out of its element.

**Certainty**: An arrow's claim: `will` (solid, unconditional site) or `might` (faint, the site sits inside a branch). _Avoid_: dashed arrows (retired)

**Unreadable**: A navigation site whose destination cannot be read from source. Never simulated and never drawn — it is reported by `spool flows` and to agents, where the fix is. A site the render answered — including by producing no attribute at all — is not unreadable, so an optional prop left undefined is no walk rather than a dark one.

**Walk**: Traversing navigation from an entered frame or in the player; a walk can flip a derived edge's verified mark.

**Scenario**: The `{state}` seed a play session boots from; frames never branch on which scenario is active. _Avoid_: preset

**Play session**: One run through the flows: name-stack history, state seeded from the scenario. The session is the page, so reloading the tab starts it over.

**Player**: The surface that plays a connected journey as one composed document, locally or from an exported website. Its inner viewport uses the available window height and a width capped at the active frame's authored width; content scrolls without scaling. _Avoid_: preview

**Edge bar**: The local player's 30px strip for switching frames, sharing and window controls. In a browser tab it can be hidden and recalled from the top edge; the Mac app keeps it in the native window. _Avoid_: toolbar, HUD, overlay, pill

**Accel**: The one modifier a platform binds its own commands to: cmd on Apple, ctrl everywhere else, never a hardcoded meta key. Spool's own gestures all live behind it, because spool never takes a plain key from a live frame — every ordinary key belongs to the prototype being used, its own `esc` included.

### Agent surface

**Verbs**: The read-only agent CLI: `selection`, `flows`, `shot`, `logs`, `url`, `skill`. Agents author by writing frame files, never through a spool command.

**Selection**: What hands last pointed at, served to agents as read-only context: always a list, frames or elements, each with its path and — for an element — what the source calls it, the lines it spans, its selector and its excerpt.

**Selection block**: The selection as one block of text, and the only rendering of it: the bytes `spool selection` prints are the bytes a turn's prompt carries for the same moment, so a CLI agent and the agent in the rail read one contract. Every entry always contributes its pointer and only excerpts are ever elided, which the block states when it happens. Nothing pointed at prints nothing, because an empty block would be a shape claiming the moment had one. _Avoid_: context payload, prompt preamble

**Chip**: One entry of the selection in the composer, riding out with the message without being asked for. The strip takes one line of the composer and never two: either every chip fits or it is a count that opens into a droppable list, and there is no third shape. A chip's dismiss control deselects on the canvas, because two picks of one list row are one string in the rail and two boxes out there. The frame the hands stepped into is an ordinary chip with the control taken off, at full strength. _Avoid_: pill, tag, token

**Attachment**: A reference image riding with a prompt as base64 over the stdin the turn already opens. Look-only: nothing is written, so the app-owned folder gains no inbox, no lifetime and no deleter, and the agent's own transcript is the durable copy. A browser never reveals a dropped file's path, which is why an attachment travels as bytes and never as a location — the same reason an asset swap sends the bytes and lets the daemon decide where they land. It arrives by paste or drop, and its receipt is the picture under the words in the transcript. _Avoid_: upload, file

**Shot**: A headless, scenario-seeded screenshot of one frame in spool's own browser, never taken from the canvas.

**Skill**: The teaching text behind `spool skill`, under the completeness contract: if it is not in the skill, spool does not do it.

**Engine**: The person's own installed agent that owns a thread's model conversation, authentication, model offers and permission enforcement: Claude Code, Codex through `codex app-server`, or pi through `pi --mode rpc`. Spool ships no engine of its own. A thread stays with the engine it started with; a thread the removed bundled engine left behind keeps it as a read-only owner, readable and never continued. _Avoid_: bundled engine

**Model session**: The durable context an engine uses to continue a thread's conversation. Its reference identifies that exact context within the engine's own storage; the rail store is a separate record.

**Turn**: One exchange with the agent, from the human's input to its ending. The daemon holds it independently of the viewer; its engine supplies agent events and accepts answers and Stop. _Avoid_: run, session, request

**Spawn**: The daemon starting the developer's installed agent for one turn, using its existing authentication and supported user settings. Claude Code, Codex and pi each get a process per turn.

**Framing**: What spool appends to the agent's system prompt at spawn — five lines saying what the agent is for, plus `spool skill`'s overview taken from the same function the verb prints.

**Agent event**: One member of the internal union every adapter feeds and the rail renders. Modelled richest-first on what Claude Code emits; a type nobody modelled is carried rather than fatal. _Avoid_: message, chunk

**Adapter**: The translation from one runtime's wire format into agent events, and nothing else — it names no frames and parses no tool arguments. Claude Code's is the first; a second needs no rail change.

**Capture**: A recorded window of a real agent session under `fixtures/captures/`, read by both the shipped tests and the dogfood canvas. The captures are the authority: read one before drawing a state, and before claiming one is missing.

**Prose**: The agent's own words in the transcript, rendered as markdown and never clamped — a message has no call to outlive, and rendered, the thing that makes it long is the thing that makes it skimmable. The subset is the corpus's: bold, inline code, fenced blocks, blockquotes and both list kinds, and no headings, because no message that reaches a log has one. A marker the message has not finished writing is closed rather than held back, and a lone bullet or number waits for its space, so what is drawn is always a prefix of what will be drawn. A settled word leaves no element behind; the arriving window is the only thing wrapped. _Avoid_: message, bubble, assistant text

**Pace**: When a character of an arriving message is allowed on screen — one every `min(12ms, 250ms ÷ pending)`, so the further behind the edge is the faster it moves and the floor is 83 characters a second. A closed form over the delta schedule rather than an accumulator, never ahead of the wire and never unwriting a character, costing up to 0.8s of lag and finishing 0.26s after the last delta. A word fades in at 170ms on arrival and the caret at the live edge is static, because every fade completes during a pause. Stillness is a jump cut rather than a slower one. _Avoid_: typewriter, throttle, animation speed

**Row**: One tool call in the transcript, as one line: a mark, a verb and a subject in spool's own nouns, with the path, command or wire name it stands in for behind a disclosure closed by default. Five states — pending, running, done, failed, stopped — where stopped is a call that never ran because a hand stopped it, told from failed by the wire's non-execution kind. The subject is the place where it names a frame: pressing it takes the canvas there, and a run's count sits outside that target because the count belongs to the call. A frame the project no longer has is struck and inert, and which frames those are is handed in rather than inferred. _Avoid_: log entry, event, message

**Plan**: The list a turn writes for itself, off the line and onto a strip above the log: one line carrying a count and the agent's own present-participle phrasing for whatever is running, opening into the tasks. It is the one thing that earns a place off the line, because it goes on changing after the call that wrote it — written in nine seconds, then moved across the next nine minutes and sixteen rows. Both phrasings are the agent's own, and a task nobody has started is the one thing in this rail that is pending. Per thread: a delegate's own list stays inside its own transcript. _Avoid_: todos, checklist, tasks pane

**Delegation**: A sub-agent as the transcript draws it: one row with the runtime's current step underneath while it runs. It never expands into the delegate's own transcript rows, so a fan-out stays one line per delegate. The step changes as the delegate moves and leaves when it settles; the row settles on its task rather than on its own result, which is a launch receipt at 84ms. _Avoid_: subtask, child turn, thread

**Designer**: Spool's own sub-agent, handed to every engine on each turn from spool's state: one brief, one direction drawn as frames. A fan-out of directions is one designer per direction, each a delegation in the rail. _Avoid_: design agent, worker

**Run**: Consecutive writes to one frame drawn as one row with a climbing count (`edit home ×6`). The next thing the log draws ends it, per thread; time is never the rule, because gaps inside a run reach 15.2s while the shortest gap between two runs is 17.5s. _Avoid_: batch, group, collapse

**Ask**: The turn waiting on the person, which is the one state in this rail that ends when somebody acts rather than when something arrives. An approval and the agent's own question ride one control request and are told apart by a flag on it: an approval leads with the agent's own written description and takes allow, always or deny, and a question leads with its own options and their whole descriptions and takes a pick, a sentence typed in the composer, or a wordless dismiss. Prose is a first-class answer the runtime prefers. An ask parks the turn and stops the clock, and nothing spool runs ever answers one or expires it. A connector's structured elicitation is declined instead, and no dialog kinds are declared, so a generic dialog is never received. An ask hangs off what it concerns rather than standing as a block of its own: an approval about a frame opens out of the turn's line as "Waiting on you"; a question whose options name the turn's frames turns its grid of pictures into the choice; a designer's ask hangs under its own tile; and an ask about no frame, an approval to run `npm install` as much as a question, is a quiet card at the end of the chat while the turn's line reads "Waiting on you". With the rail shut it stands on the canvas under its frame, or under the spot reserved for it. Answered, it folds to one quiet line where it was asked. _Avoid_: permission prompt, modal, confirmation

**Always**: An approval answered for the rest of the thread, using the rules the request suggested for itself moved to the runtime's own thread scope, or held by spool in memory for the thread where that scope dies with the turn's process, as Codex's does. Written to no file, because the complaint is repetition rather than a missing permanent grant, and absent rather than dead where the request suggested no rule — spool composes none of its own. _Avoid_: remember, don't ask again, grant

**Stop**: Explicitly ending a running or waiting turn with the Stop button in the composer footer, returning queued messages to the composer. Escape dismisses or leaves interface surfaces without stopping the agent. _Avoid_: cancel, abort, kill

**Queue**: The messages spool holds while a turn runs, held by spool rather than by the runtime — take-back has no wire, every adapter queues alike, and the rail draws its own state rather than a picture of another process's. Enter during a turn accepts a message into the list and writes nothing mid-turn; the whole list goes down the moment the result arrives, in order, as one turn, each message carrying the selection block from its own Enter rather than from firing time. Each waits at the end of the log, shaped as the ask it will become with its rail dashed and its words faint, and a Take back under it, so firing is that message becoming the ask in the same place. One invariant covers both exits: words that leave the queue un-fired land back in the box, above the draft, in fire order, one blank line apart — so a stop and a take-back have the same outcome for the words involved. _Avoid_: outbox, buffer, pending messages

**Thread**: One conversation in a project, with a permanent engine owner, its model session and Spool's saved rail picture. Switching or closing a thread changes what the person sees without moving the canvas or deleting its saved work. _Avoid_: session, chat, conversation tab

**Life**: What a thread's 14px mark says, in five readings of which four draw. Streaming draws nothing and keeps the cell aligned; running turns; waiting is unread's disc held inside running's ring, the loudest of the three because it is the only one actually stuck; unread is a solid dot at text strength; read is a hollow one, because out in the column the mark is the whole of the thread and a thread you cannot see is one you cannot press. Colourless throughout, because state in this rail is motion and the one accent belongs to the selection. Waiting and unread are told apart by what clears them: a look clears unread wherever the looking happened, and nothing about looking answers a question. Its three causes — a parked question, an unanswered approval, a login that is not there — share the one mark; a usage wind-down is not one of them. _Avoid_: status, badge, indicator

**Spine**: Retired (#364). The threads were once a column of marks down the rail's outer edge, then a nameplate over the log; the agent pane's header now holds only the thread's title, which drops the thread switcher, and the plus. Rows in the switcher name a thread's engine only when it is not the usual one, and what is moving in another thread is one small Life dot on the agent's rail icon. _Avoid_: sidebar, tab rail, nameplate

**Store**: Spool's saved rail picture of a thread: its drawn entries, draft, queue and thread state, kept separately from the engine's model session. Missing engines or model sessions leave this picture readable. _Avoid_: model session, cache

**Offer**: What the runtime says one thread may pick, asked of it at runtime and shipped in no table: one control request answers with its own rows, each carrying its name, its sentence and its own effort levels, so a new or retired model needs no spool release. It answers with the choices it offers rather than every alias it accepts, which is what leaves one axis — no models-versus-policies split, and a wider context window as one row rather than a model with a switch beside it. A model with no levels has no effort control at all, because the absence is data. The rows come back the same for every thread and which of them is answering does not, so the ask is a thread's and switching one re-asks. _Avoid_: model list, catalogue, registry

**Readout**: Which machine is answering and how hard it is thinking, drawn from the runtime's own report and never from what spool asked for — a control that renders its own state is guessing, and this one can be overruled by an alias the runtime will not take or an effort level the environment holds. The name is the runtime's own, uncased and unshortened: it truncates with an ellipsis and is never rewritten, because two offered rows can resolve to one model with only a parenthetical between them, so a shortened name is not a short name for this machine but the correct name of a different one. Choosing is a shortcut for the message a person could type, so both go the same way and neither is a second source of truth, and the choice is the thread's: it rides every spawn of that thread as a flag, because a resume restores the conversation and a command typed into one turn is a fact about that turn. _Avoid_: model picker, selected model, current settings

**Usage window**: The one usage limit the runtime hands over, out of the six it can name — spool picks neither the window nor the threshold, both are chosen upstream by representative claim and then by a burn-rate table spool does not own. It lives in the model menu rather than beside it, because the remedy for reaching one is a model switch every time and the fact belongs next to the remedy. Absent until the runtime warns: below that the payload carries no utilization at all, so there is no gauge to draw and the line cannot become chrome. Reaching one is a wind-down rather than a wall — the agent is told to finish or checkpoint and start nothing new, which is why the log says so, and the failure mode is a turn that half happened. Nothing is drawn about overage, which is billing spool has no relationship to narrate. _Avoid_: quota, rate limit bar, usage meter

**Wall**: What the rail is when no supported agent is on the machine to spawn: a sentence and one install line per agent (Claude Code, Codex, pi), each with a copy button, in the transcript's place, before the first keystroke. An agent that is there but older than spool runs is not installed either, and its line says it needs updating and gives the update line instead. It looks again on Check again and whenever the window regains focus, because whether a command resolves on PATH is a fact about this machine that spool owns the right to look up, that costs nothing to answer and that is stable. The composer stays and is dead — take it away and the rail is a sentence with no evidence of what the rail is for, leave it live and it collects a prompt for nobody. Its look is allowed to keep failing, because installing takes minutes rather than the second a login takes, so a second press is the normal case and each one leaves a quiet line. Only a look that came back and found nothing draws it: a door that said nothing is not a machine with nothing on it. Colourless, because the one accent means a chip and a box are one object and this is not even a failure. _Avoid_: error state, empty state, setup screen

**Bounce**: A turn that came back refused because nobody is signed in. Whether a runtime is signed in is a fact inside another product, and spool reads none of its private credential or config files to find out — it asks by spawning, which is the thing it was going to do anyway, so the refusal lands when the first token would have rather than instantly, and a composer that refused before sending would be spool guessing wrong the first morning somebody signs in without telling it. It reads in two places on the one test that separates them: the standing fact is a strip on the shelf the plan would take, since a plan belongs to a turn that is running and this exists because none can, and the moment itself is in the log, in the runtime's own refusal wording verbatim with one sentence of spool's under it naming the terminal, because the runtime's own remedy is a slash command inside a session spool does not spawn. The words that bounced are kept: they are in the log in the human's voice from the instant Enter was pressed, checking again sends those same words, and the turn draws no second copy of them. The check asks the runtime and answers with a who, said once at the moment spool starts using that login; a check that comes back with the same answer leaves one quiet line. Nothing anywhere is drawn about API keys and no field exists to paste one into. _Avoid_: auth error, login screen, sign-in prompt

**Agent hand**: What the canvas draws at a frame while an agent is working it: one small ink square per working agent, its **companion**. Not the **Hand** tool and not the **Hands**, which are both the human's: this one is the agent's, it is drawn rather than held, and it takes no pointer. The square does what the agent does, so a glance at the canvas says it: it is the caret on the newest line while a frame streams and rides down the edge as the picture draws in; slides down the frame's left wall while it reads; hops to the block a write changed and rings it; throws four corners out while it photographs; takes the whole frame into itself as it deletes; and becomes the breathing waiting ring while it asks. Left alone about two seconds it dims, and it leaves when the turn ends. Words only when two or more agents share the page, and then only each designer's take. Ink and greys only, never the selection red, and nothing moves the camera. Its timings are the agent's motion tokens. _Avoid_: activity indicator, agent cursor, progress overlay, avatar

**Presence** (agent one): Where an agent's companion stands, which needs only a name off the wire: the frame its latest call or write named, else the spot reserved for its designer, parked at the frame's top-right corner while nothing is happening there and at its left foot while it waits on a person with the rail shut. Its act — new, read, edit, shot, delete, ask, idle — is folded from the transcript, so it draws on any visible frame at any zoom. A frame drawn below the readable threshold gets the presence and nothing else. _Avoid_: spinner, badge, halo

**Located mark**: The half of the agent hand that is a fact about the pixels, and the only channel that says *what* changed: the box one write changed, measured by the document showing it, which the companion hops to and rings. A box needs a document, and the range comes from the daemon, which owns the file, answering the canvas, which owns the transcript. One write marks every frame that renders it, which is what a shared component is. _Avoid_: highlight, diff overlay, flash

### Laws

**Parity law**: Spool chrome must never alter frame behavior; a frame in spool behaves exactly like its bare document.

**Boundary law**: `shared/ui/` components have feel (own state) but never knowledge: no `"spool"` imports, props only. This is what keeps them product-importable.
